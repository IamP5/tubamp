0. ARCHITECTURE (who does what)
-------------------------------
- Real host of the cab DSP is IK::MAF::AT3::Cabinet (not Comp::CabAT5; the Comp:: classes are
  model/GUI metadata). Functions: DefineParameters 0x154c55c, OnSampleFrequencyChange 0x154a96c
  (prepare), ProcessBuffer 0x1551d2c (render), SetParameter 0x15406dc (41 KB), CompleteBuild 0x154f0cc.
  D: xref scan of callers of Conv::IR::IR 0x102bc50 and Conv::Module::Initialize 0x102cc58.
- The cab state object (at Cabinet+0x210) holds: two IK::KIS::TK::Conv::Module (mic1 @+0x260,
  mic2 @+0x268) with their Conv::IR (+0x250/+0x258), the FlexiCab IR builder
  FX::AT5::CabinetModuleAT5::Cab (TryUpdateFlexiCabIR 0xf1128c), Vibratone DynamicConv x2,
  LeslieII x2, 2x Convolver::Convolver for ambience (+0x4de0/+0x5188),
  2x ConvolverAutoResampling2 for the Custom IR loader (+0x5610/+0x60f8).
  D: OnSampleFrequencyChange 0x154b728..0x154b95c, CompleteBuild 0x1550f04..0x1550f94.
- Cab IR = synthesized offline (non-RT) from measured per-position IRs, then loaded into a
  zero-latency partitioned convolver. Mic position is NOT a filter; it is IR interpolation.

1. CONVOLUTION ENGINE
---------------------
Conv::IR::IR(data, len, bool zeroLatency, int block) 0x102bc50 picks one of 4 engines (IR+8 = type):
  len <  8192, !ZL -> type 0 UniformSegmented, partition = min(len, block)
  len <  8192,  ZL -> type 2 head = min(len,block) taps direct-form FIR (Impl::TimeDomain) +
                      UniformSegmented tail from sample `head`             D: 0x102bc78..0x102bce4
  len >= 8192, !ZL -> type 1 MultiSegmented (non-uniform)
  len >= 8192,  ZL -> type 3 head `block` taps direct FIR + MultiSegmented tail D: 0x102bcf0..0x102bd4c
Module::SetIR 0x102c374 stores a pointer-to-member process fn per type; ZL variants run
TimeDomain::Process + partitioned tail and sum (ProcessMultiSegmentedZeroLatency 0x102c514,
fadd loop 0x102c5e4). FFT = Apple vDSP (vDSP_create_fftsetup / ctoz / fft_zrip / ztoc / vsmul
by 1/N, D: MultiSegmentedIR ctor 0x1029fe8..0x102a068; stubs resolved via indirect symbols).
Non-uniform schedule (MultiSegmentedIR ctor 0x1029d80, only built when base block == 64,
`cmp w3,#0x40` 0x1029dc0): first 320 taps in a 512-pt FFT; then DoSegmented(N,start,end) with
partition N/2, count=(end-start)/(N/2)+1 (D: DoSegmented 0x1029908..0x1029918):
  FFT 512 for taps 320..575, 1024 for 576..1087, 2048 for 1088..2111, 4096 for 2112..4159,
  8192 (partition 4096) from 4160 to end (len >= 32768); shorter IRs stop at the 2048/1024 stage.
  => Gardner-style doubling segments.
CAB USES: IR(len, ZL=true, block=128) -> type 2 for both mic convolvers
  (D: 0x154b768 `mov w3,#1`, 0x154b76c `mov w4,#0x80`, also 0x154b804/0x154b808).
  len = 2048 if fs < 88200 else 4096 (D: 0x154a9e0..0x154a9f8, 88200.0 = 0x47ac4400).
  => 128 direct-form taps + 15 (or 31) uniform partitions of 128 (FFT 256). LATENCY 0 samples
  [inferred from TimeDomain head = partition size, consistent with ZL naming].
  A third small IR (len 128 / 256 by fs, block 128) at +0x6c18/+0x6c20 [purpose not determined].
Scheduling: no thread/semaphore primitives in TK::Conv / TK::Convolver code (grep of dumps);
  all convolution runs per audio block on the render thread [inferred]. Big-FFT spreading:
  separate class Convolver::FFTUniformDistributed (0x1030758/0x1030948) used by
  Convolver::Convolver (ambience/custom IR), which picks stage sizes by thresholds 1024/2048 and a
  96-tap figure (D: 0x102ce8c..0x102cf58); NOT fully decoded.
IR building/loading runs on a std::thread (IRPool::LoadCabinetImmediate via std::thread ctor
  0xf176e8, joined in TryUpdateFlexiCabIR 0xf1136c), with atomic load-state flags (ldar/stlr at
  pool+0x4b08 per cabinet).

2. IR LENGTH, TRUNCATION, FADE, DECIMATION
------------------------------------------
- Runtime cab IR length: 2048 samples at 44.1/48 kHz, 4096 at 88.2/96 kHz (~43-46 ms) (see 1).
- Per-position source IRs: resampled to session rate by DiskRawIRFactory with length
  IRPool+0x7c and fade fraction 0 (descriptor built 0xf16c60..0xf16c68: rate, len, `str xzr`).
- Composition buffers are 8192 floats (Convolve(...,8192,...,8192,...,8192) 0xf11c80..0xf11c8c,
  memcpy 0x8000 bytes) [their exact role = cabinet x speaker variant composition, inferred].
- DiskRawIRFactory::Create 0x103623c generic loader: WAV parse -> if file rate != target and
  target != 0: ResamplerOneShotHQ(srcRate,dstRate,16,...) (0x10365c4..0x10365e4); target length
  default = srcLen*dst/src (0x10363dc..0x10363ec); optional raised-cosine fade-out
  0.5+0.5*cos(pi*n/N) over the last `fade*len` samples (0x1036658..0x10367dc); zero pad
  (0x10367fc). No normalisation in this path.
- IR "decimation" (param gcIRDecimation, 2 states; AT5NewFeaturesGUID::scIRDecimation is only a
  feature/preset GUID): MicPlacementMixer::Generate takes a DecimationLevel (stack arg
  [x29+0x20], test 0xf17ecc). Level==1: full-grid bilinear (see 5). Otherwise: the 4 CORNER IRs
  (indices 0/14 and 0/4) are used with the raw 0..1 position as weights (0xf17f44..0xf17f58).
  => Decimation = reduce the measured grid to 2x2 corners (less memory/loading)
  [function decompiled; purpose inferred].

3. RESAMPLING
-------------
- FlexiCab IRs: resampled ONCE at load to the session rate (DiskRawIRFactory, ResamplerOneShotHQ,
  arg 16 = filter size parameter, probably half-length in zero crossings [guess]); convolver then
  runs at session rate. Convolver re-created on rate change (OnSampleFrequencyChange).
- TONEX CabVIRLight IRs stored/requested at 44100 Hz, 2048 samples (LoadIR 0xfb9198, descriptor
  rate 0x472c4400 = 44100.0 at 0xfb930c, memcpy 8192 bytes 0xfb933c).
- ConvolverAutoResampling2 (custom IR): SetSampleRate 0x102fca4 computes max IR length
  ceil(maxLen*fs/minIRRate) (cap 2*maxLen in modes != 0), GCD of the two rates (binary GCD in
  Update 0x102fe94..), and an SSRC<WindowedSinc 32 taps x 64 phases Blackman-Nuttall, HalfBand>
  rational resampler (Initialize 0x102fac4). Modes 1/2 allocate n/2, n/4, n/8 buffers
  (SetMaxBufferSize 0x102fbe0..0x102fc90) => it can also run the convolution at a decimated rate
  with audio resampled around it [inferred]; the cab custom IR initialises mode 0 (w2=0 at
  0x1550f64). Initialize(9600, 33075.0, 240000.0, 0, 0): 33075 = 44100*0.75, 240000 = 192000*1.25,
  matching IR Size 0.75..1.25 (size = playback-rate stretch of the IR) [inferred].

5. MICROPHONE POSITION MODEL (FlexiCab "VIR")
---------------------------------------------
- Measured IR per grid position, file name "KISResAT5/FlexiCabAT5/AT5/%s%s%s_%02d_%02d_90.0.wav"
  (string 0x31dff2f): cab path, speaker region (e.g. "-ExternalBlack"/"-InternalBlack",
  tables 0x34464b8, 0x3447c70), mic ("_Akg414","_NeumannU87","_ShureSM57","_RoyerR121"
  0x34464d8..), two grid indices, mic angle ("_90.0","_45.0" 0x34464f8).
- Grid: up to 15 x 5 positions per (speaker, mic, region): IR pointer rows of 120 bytes
  (15 x 8) and 600 bytes per set (5 rows); lengths in parallel int arrays at +0x9e8
  (Generate 0xf17fd4..0xf18010).
- SetParameter converts X,Y (-1..1) to polar: r = sqrt(x^2+y^2) -> +0x21f4,
  theta = round(atan2(.)*180/pi) degrees -> +0x21f8 (0x1541464..0x15414d0).
- Generate(out,len,?, r, theta, distance, Y, X, nCols, nRows, arrangement, positions,
  ..., DecimationLevel) 0xf17e80:
  * index i = r*(nCols-1), j = distance*(nRows-1), clamped to nCols-2/nRows-2, fractions fx, fy
    (0xf17ed8..0xf17f2c). So the grid axes are RADIUS from speaker centre (15) x DISTANCE (5)
    [axis meaning inferred from the polar conversion].
  * BILINEAR, 4 neighbours, TIME DOMAIN, linear weights (1-fx)(1-fy), fx(1-fy), (1-fx)fy, fx*fy
    via IRComposition::Mix / MixAdd (0xf18014..0xf18084). No per-IR alignment shift (delay args 0).
  * theta == 0 -> one radial set; theta != 0 and != +-180 -> the 4-neighbour result of a second
    set (other region) is blended with weight |theta|/180 (0xf18298..0xf18410): 8 IRs total.
  * Other speakers of a multi-speaker cab (SpeakerArrangement, up to 4): a far-grid IR is added
    with delay = (sqrt(dx^2+dy^2+(0.1*d)^2) - r/2)/340 m/s * fs samples and a gain using
    powf(3.16, .) (0xf18468..0xf18580); ApplySpeakerSwap 0xf19be8 handles per-speaker model
    swaps (CabSpeaker0..3). [geometry details partly inferred]
- Mic angle: 2 states (45/90 deg) = separate measured sets (file suffix), no interpolation
  [inferred from param n=2 + names].
- Inter-mic timing: farther mic delayed by (d_this - min(d1,d2))*0.01/340*fs + 0.5 samples
  (0x3c23d70a = 0.01, 0x43aa0000 = 340.0; TryUpdateFlexiCabIR 0xf120b4..0xf120e4, shift by
  bzero+memcpy 0xf12344..0xf12374). Distance stored in cm. This reproduces physical delay; it is
  NOT automatic phase alignment. No cross-correlation alignment found.
- 2 mics per cab (Mic1/Mic2), each its own Conv::Module; per mic: Model (18), X, Y, Distance,
  Speaker (4), Angle (2), Level, Pan, Phase (2). No solo/mute per mic (only Ambience has Solo).
